# packages/

Shared package placeholders. **Not implemented yet.**

Planned packages (as specified by the Project 117 architecture):

- `types` — shared TypeScript types mirroring the backend API contracts
- `api-client` — typed client for the backend gateway
- `ui` — shared UI components
- `config` — frontend configuration
- `validation` — shared input-validation schemas
- `events` — event/streaming helpers (SSE chat)

These are only relevant once the web/mobile apps are built.
