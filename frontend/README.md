# Project 117 — Standalone Workbench (Frontend)

> **Notice:** This `frontend/` (Vite + React) package is a secondary, optional, backend-decoupled workbench. The canonical console for Project 117 is located in `apps/web` (Next.js 14). This directory is maintained for standalone offline simulation and is not covered by the CI build matrix.

## Overview

This package contains the Vite-based simulation workbench canvas, node components, and WebSocket bridge.
For the canonical production web console, please see [`apps/web`](../apps/web).
