# Elliott 29M9-6 — Vibration and Temperature Alarm Limits (excerpt)

## Table 7-2: Vibration limits, DE / NDE bearing housings

| Level | Overall velocity (mm/s RMS) | Action |
|---|---|---|
| Normal | up to 5.8 | none |
| Alert | 5.8 - 7.1 | investigate within 7 days |
| Alarm | 7.1 - 11.0 | reduce load, inspect |
| Trip | above 11.0 | shut down |

## Table 7-5: Bearing temperature limits

| Level | Temperature (degC) | Action |
|---|---|---|
| Normal | up to 72 | none |
| Alert | 72 - 85 | investigate lube supply |
| Alarm | 85 - 95 | reduce load |
| Trip | above 95 | shut down |

Running speed: 2976 rpm (49.6 Hz). Rotor mass: 412 kg.
Recommended re-baseline interval: 90 days or after any bearing/coupling work.
