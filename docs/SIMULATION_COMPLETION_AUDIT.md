## 2. Blocker-by-blocker: Problem → Fix → Test → Evidence

### B1 — Dependency graph pointed outside the repository

* **Problem** `pyproject.toml` had `lightrag-hku = { path = "../LightRAG-main", editable = true }` and pyright `extraPaths = ["../localGPT-main"]`. Neither directory exists in a clean checkout, so `uv sync` fails before installing anything.
* **Fix** Path source removed. `lightrag-hku` is now a versioned PyPI **optional extra** (`--extra graphrag`); a second `localgpt` extra covers the vendored pipeline's extra requirement; pyright's `extraPaths` now points at the in-repo, optional `vendor/localGPT`. Nothing was deleted — both integrations stay wired and degrade *visibly*. `docs/SETUP.md` documents exactly how each is supplied, including an air-gapped wheelhouse path.
* **Test** Inspected the resulting `pyproject.toml`; no path sources remain; the whole simulation pipeline suite runs with the standard library only.
* **Evidence** `test_integration_pipeline.py` completes with zero third-party packages installed beyond pydantic. `docs/SETUP.md` §0/§2/§9.
* **Status** PASS (resolution of the PyPI extras themselves is **UNVERIFIED** — no network here).

### B2 — Mock mode was the default

* **Problem** `NEXT_PUBLIC_DATA_MODE` defaulted to `mock`; the browser ran its own engine and nothing reached the backend.
* **Fix** `next.config.mjs` and `adapter.ts` both default to `live`. `EmbeddedAdapter` is constructed **only** when the value is literally `mock`, and then logs a loud console warning. Network failures raise `BackendUnavailableError` — there is no code path from live into embedded. Added `checkBackendHealth()` against `GET /api/simulation/health`; the plant page shows `live backend · <db>`, `backend unreachable: <detail>`, or `mock mode (development only — not backend data)`, and on load failure renders "Backend unavailable — plant not loaded" with the exact uvicorn command.
* **Test** Source-level: no fallback branch exists. Runtime browser behaviour **UNVERIFIED** (no `node_modules`).
* **Evidence** `apps/web/src/lib/sim/adapter.ts` (`DATA_MODE`, `BackendUnavailableError`, `createSimAdapter`), `apps/web/src/app/console/simulation/plant/[id]/page.tsx`.
* **Status** PARTIAL — implemented, browser-unverified.

* **Test** `[1] Randomised end-to-end` in the integration suite.
